# Sequence Detector | Verilog HDL

A Verilog HDL implementation of a Finite State Machine (FSM) based Sequence Detector designed to detect a predefined binary sequence in a serial input stream.

## Overview

This project demonstrates the design and verification of a Sequence Detector using Finite State Machine (FSM) concepts. It highlights state transition logic, sequential circuit design, and RTL implementation in Verilog HDL.

## Features

- Finite State Machine (FSM) Design
- Verilog HDL RTL Implementation
- Synthesizable Design
- Testbench Verification
- Xilinx Vivado Compatible
