# Sequence Detector | Verilog HDL

A Verilog HDL implementation of a **Finite State Machine (FSM)** based Sequence Detector designed to detect a predefined binary sequence in a serial input stream. The project includes RTL design, simulation, synthesis-ready Verilog code, and verification using a testbench.

---

## 📌 Overview

This project demonstrates the implementation of a Sequence Detector using FSM concepts. It covers state transition logic, sequential circuit design, RTL coding in Verilog HDL, and functional verification through simulation.

---

## ✨ Features

- Finite State Machine (FSM) Design
- Mealy/Moore FSM Implementation *(change according to your project)*
- Synthesizable Verilog HDL Code
- Testbench for Functional Verification
- RTL Schematic Generation
- Simulation Waveform
- Xilinx Vivado Compatible

## ▶️ How to Run

1. Open the project in **Xilinx Vivado**.
2. Add the Verilog source file.
3. Add the testbench.
4. Run **Behavioral Simulation**.
5. Verify the detected sequence in the waveform.
6. Run **Synthesis** to generate the RTL schematic.
